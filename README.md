## 🚀 How to Run the Code

1. Check Node.js version:

   ```bash
   node -v
   ```

2. Clone the repository:

   ```bash
   git clone https://github.com/raj-ranjan-70/practice-codes.git
   ```

3. Go into the project folder:

   ```bash
   cd practice-codes
   ```

4. Run a file:

   ```bash
   node filename.js
   ```

5. Install dependencies (if needed):

   ```bash
   npm install
   ```
